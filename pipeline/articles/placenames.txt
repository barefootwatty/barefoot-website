# Verified Top End place names.
#
# WHY THIS FILE EXISTS: the lesson transcripts come off an automatic
# transcriber, which mangles proper nouns badly — "Shaw Bay" for Shoal Bay,
# "Kokatoo" for Kakadu, "Mganella" for Murgenella. GW's rule, and he is right:
# a wrong place name is a reputation killer on a guiding site. Locals spot it
# instantly and it undoes the authority the whole article library is for.
#
# THE DISCIPLINE: if a place name is not on this list and you cannot verify
# it, LEAVE IT OUT of the article. Write "one of the bigger rivers" instead of
# guessing at a name. Never invent, never approximate. Add a name here only
# once it is confirmed — from GW, from a map, or from an unambiguous source.
#
# tools/check_places.py reads this file and flags anything unrecognised in the
# article sources before they ship.
